# ET-3850 Mod Lab

Open research and a small companion client for an owner-modified Epson ET-3850. This repository contains no Epson firmware, printer credentials, personal photos, or firmware-install bypass.

## What we verified on one printer

- The printer runs Linux 4.4.27 on ARMv7.
- An owner-built firmware modification started a password-gated root shell. A live `id` command returned `uid=0(root) gid=0(root)`.
- The modified `nwsoc` executable was present on the running printer. Its MD5 digest matched our patched build.
- The live Realtek 8723DU driver reported `rtw_power_mgnt=0` and `rtw_enusbss=0` after boot. These settings disable two power-saving behaviors; long-term Wi-Fi reliability has not yet been measured.
- One JPEG cake print submitted by IPPS reached the printer's `completed` job state. Physical output awaits a direct confirmation.

This does **not** mean the printer's stock firmware has SSH, or that a personal photo can be selected as its LCD wallpaper. Our custom service uses Telnet on port 2323. Its password was generated by us; we did not recover Epson's root password. The stock LCD wallpaper menu offers solid colors, and the image resource we modified offline is not confirmed as the home-screen background.

## Companion client

The client probes an address you supply and can connect to the password-gated shell **after** a printer has been modified. It does not install firmware.

Requires Python 3.12 or earlier because the standard-library `telnetlib` module was removed in Python 3.13. No third-party packages are needed.

```powershell
python et3850_client.py probe 192.168.0.12
python et3850_client.py status 192.168.0.12 --password-file C:\path\to\your-password.txt
python et3850_client.py shell 192.168.0.12 --password-file C:\path\to\your-password.txt
```

The password file stays on your computer. The client does not log it or transmit it anywhere except to the specified printer. Telnet traffic itself is plaintext, so use the custom shell only on a trusted local network.

## How the firmware differs from this client

The patch runs **on the printer**: it changes the network program's Wi-Fi driver arguments and starts the private login service at boot. The Python client runs **on your computer** to inspect or connect to that service. The ET-3850 already runs Linux; we have not replaced its operating system with a general-purpose distribution.

The modified package did not have a valid Epson ECDSA signature. We rebuilt its ordinary record integrity fields, then investigated an updater acceptance issue. A live install was verified by the custom startup marker, root login, executable digest, and driver parameters. The exact bypass and installation code are reserved for coordinated disclosure.
